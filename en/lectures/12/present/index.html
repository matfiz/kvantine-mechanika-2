States that stay and states that leave: decay

12.4 A state that decays exactly

Both obstacles can be avoided, but only together.

A function of a complex variable is analytic on an open set if it has a convergent power series about each point of that set. An analytic continuation is an analytic function on a larger region that agrees with the original function wherever both are defined. A function is meromorphic if it is analytic except at isolated poles. Near a pole z0z_0z0​ it has the form b(z)/(z−z0)jb(z)/(z-z_0)^jb(z)/(z−z0​)j, where j≥1j\ge1j≥1 and bbb is analytic with b(z0)≠0b(z_0)\ne0b(z0​)=0. The pole is simple when j=1j=1j=1.
